Projects

2025–2026

Stockr

A research pipeline that asks whether machine learning can predict the S&P 500, and answers honestly. Nine models, retrained every six months on data they could have known at the time, tested with block-bootstrap and Diebold-Mariano statistics.

The finding: next-week direction is a coin flip for every model I tried, but volatility is forecastable. Sizing positions to the forecast cut the worst drawdown from 57% to 42% and slightly raised returns.

Code and full report on GitHub

Python, XGBoost, scikit-learn, SHAP, pandas, GitHub Actions

−15 pts max drawdown (57% → 42%)

Fall 2026

Signal Lost

A top-down stealth game I wrote from scratch in Go: sneak past security drones, repair three relays per sector, and reach the airlock. Every run generates a new station from a seed, with extra doorways that give each map loops instead of dead ends.

The drones run a five-state AI (patrol, investigate, chase, search, stunned). They see you through line of sight, hear repairs and decoys, alert each other, and route through doors to find you. A spatial-hash grid keeps those checks fast as drone counts grow.

Go, raylib
